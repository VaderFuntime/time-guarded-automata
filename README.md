# Time-Guarded Automata

This work introduces **Time-Guarded Automata**, an extension of classical finite automata in which transitions are enabled or disabled based on the time (word length) at which they are taken. The paper formalizes the model, studies its expressiveness and succinctness, and examines translations to standard automata under regular guard restrictions.

Key topics include:
- Formal definition of time-guarded word and Büchi automata
- Translation to NFAs using regular guards
- Stability and lateness properties
- History-Guarded Automata and PSPACE-completeness results
- Analysis of succinctness and exponential state blow-up
- Probabilistic notions such as transition odds and “lucky words”
